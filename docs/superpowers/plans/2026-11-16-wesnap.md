# 微截（WeSnap）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Windows 上实现一个自用的微信式截图工具：Alt+A 唤起、框选缩放、标注、贴图、滚动长截图，完成时存桌面并复制剪贴板。

**Architecture:** Python 3.14 + Tk 9.0 自绘遮罩界面；ctypes 直连 GDI 抓屏、剪贴板与 Win32 消息；Pillow 做图像合成与拼接算法。程序由已签名的 `pythonw.exe` 宿主运行（Smart App Control 拦截未签名 exe），配 `.vbs` 启动器与桌面快捷方式。

**Tech Stack:** Python 3.14.7、Tk 9.0、Pillow 13、ctypes、unittest、git。

**Spec:** `docs/superpowers/specs/2026-11-16-wesnap-design.md`

## Global Constraints

- 只允许一个第三方依赖：Pillow；不得引入 pytest/win32gui 等额外包。
- 不产出 exe；不要求管理员权限；不得建议关闭 Smart App Control。
- 抓屏、裁剪、保存一律使用物理像素；进程启动即设为 Per-Monitor DPI Aware（`SetProcessDpiAwarenessContext(-4)`）。
- 默认热键 `Alt+A`；默认保存目录为系统桌面；文件名 `Screenshot_yyyyMMdd_HHmmss.png`，冲突时追加 `_2`、`_3`。
- 配置与日志位于 `%APPDATA%\WeSnap\`（`settings.json`、`wesnap.log`）。
- 标注默认颜色 `#E64340`、线宽 2px；文字字体「微软雅黑」14pt（缺失时回退默认字体）。
- 长截图参数：轮询 100ms、`min_overlap=16`、`max_overlap=min(0.9h, h-16)`、灰度阈值 12/255、匹配宽度 320、画布上限 30000px 高。
- 长截图控制面板与边框条必须在抓取矩形之外；放不下则禁用长截图；会话期间隐藏全部贴图。
- 任何 WeSnap 自己的窗口都不得出现在保存的图片里。
- 不联网、不写遥测；除 `HKCU\...\Run` 的自启项外不写注册表。
- 所有 UI 文本通过 `root.after(50, ...)` 轮询队列回主线程执行，禁止在后台线程直接操作 Tk。

## Review Focus

1. **175% 缩放下的坐标一致性**：选区框住的区域必须与保存 PNG 的像素一一对应；错位 1.75 倍是最容易被忽略的失败。Task 9 的 DPI 探针与 overlay 冒烟测试覆盖。
2. **虚拟屏负坐标**：外接屏在主屏左侧/上方时虚拟屏原点为负，裁剪框计算必须减原点而不是假设从 0 开始。Task 4 `rect_to_image_box` 测试覆盖。
3. **固定表头导致长截图重复条带**：页面顶部吸附栏不随滚动移动，朴素重叠匹配会整段重复。Task 10 的 sticky-header 测试覆盖。
4. **剪贴板被占用**：其他程序占着剪贴板时不能崩或丢图；要重试、失败时保存仍成功。Task 6 重试测试与 Task 13 流程覆盖。
5. **中文/输入法文字标注**：文字工具必须能输入中文，且屏幕显示与保存结果一致。Task 5 中文 TextAnn 测试 + Task 9 手工验收覆盖。

import unittest
from PIL import Image
from wesnap.annotate import (RectAnn, EllipseAnn, ArrowAnn, PenAnn, TextAnn,
                             MosaicAnn, UndoStack, render, DEFAULT_COLOR)
from wesnap.geometry import Rect

def white(w=200, h=120):
    return Image.new("RGB", (w, h), "white")

class AnnotateTest(unittest.TestCase):
    def test_rect_and_clipping(self):
        img = render(white(), [RectAnn(Rect(-10, -10, 60, 60))])
        self.assertEqual(img.getpixel((0, 0)), DEFAULT_COLOR)
        img2 = render(white(), [RectAnn(Rect(500, 500, 20, 20))])
        self.assertEqual(img2.getpixel((0, 0)), (255, 255, 255))

    def test_ellipse_center_hollow(self):
        img = render(white(), [EllipseAnn(Rect(10, 10, 80, 60))])
        self.assertEqual(img.getpixel((50, 40)), (255, 255, 255))
        self.assertEqual(img.getpixel((10, 40)), DEFAULT_COLOR)

    def test_arrow_and_pen_hit_path(self):
        img = render(white(), [ArrowAnn((10, 10), (100, 10))])
        self.assertEqual(img.getpixel((50, 10)), DEFAULT_COLOR)

        self.assertEqual(img2.getpixel((30, 30)), DEFAULT_COLOR)

    def test_text_renders_chinese_without_error(self):

- [ ] **Step 2: 运行测试确认失败**

Run: `python -m unittest tests.test_stitcher -v`

- [ ] **Step 3: 实现**

- `frames_differ`：把两图缩成 ~64px 宽灰度，抽样比较平均绝对差，> `threshold` 为不同。
- `common_prefix_rows`：把 `prev` 与 `frame` 各缩到 64px 宽灰度，从第 0 行起逐行比较平均绝对差；连续相同（差 ≤ `tol`）的行数即返回值；上限 `int(frame.height * max_ratio)`。
- 重叠搜索（`match_width=320`，灰度、缩放到不超过该宽度）：候选 `d` 从 `min_overlap` 到 `min(frame.height - header, int(frame.height * max_overlap_ratio))`。**用 PIL 的 C 实现算分，不要写逐像素 Python 循环**：`ImageChops.difference(canvas_gray.crop(bottom d), frame_gray.crop(header, header+d)).convert("L")` 后 `ImageStat.Stat(...).mean[0]`。先步长 4 粗扫，再在最优值 ±4 内步长 1 细化。性能目标：单帧拼接 < 60ms。
- `header = common_prefix_rows(prev_frame, frame)`（`prev_frame` 为 None 时 0）。
- 有最优 `d` 且分数 ≤ `threshold`：追加 `frame.crop((0, header + d, w, h))`，`status="appended"`、`header_skipped=header`、`appended_rows=h-header-d`。
- 无匹配：用 `_contained_in_canvas`（帧在画布中逐行寻找，粗步长 4，同样用 `ImageChops` 算分）判断是否向上滚动；是则 `ignored`；否则整帧追加、`status="appended_full"`、`score=255`。
- 开头的 `frames_differ` 判断：帧与画布末段（同高）无差异 → `ignored`。
- `max_height`：追加前若 `canvas.height >= max_height` → `status="max_height"`，原样返回。
- 参数常量来自 Global Constraints，函数参数可覆盖。
