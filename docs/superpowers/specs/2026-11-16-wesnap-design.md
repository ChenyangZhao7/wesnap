# 微截（WeSnap）设计文档

日期：2026-11-16
状态：待确认

## 1. 背景与目标

给本人自用的 Windows 截图工具，体验对标微信截图：全局热键唤起 → 屏幕变暗 → 拖拽框选、拖动四边四角调整范围 → 标注 → 保存到桌面。额外支持长截图（滚动拼接）。

目标用户只有一个人（本人），不做商业级健壮性，但要做到天天用不别扭。

## 2. 范围

### 目标

- 全局热键 `Alt+A` 唤起截屏（可改），Esc 取消。
- 全屏变暗遮罩，十字光标，拖拽框选；选区内拖拽可整体移动；8 个手柄调整大小；方向键微调。
- 标注工具：矩形、椭圆、箭头、画笔、文字、马赛克、撤销。
- 长截图：框选区域后进入滚动模式，用户自行滚动鼠标滚轮，程序持续抓取并拼接，点「完成」结束。
- 贴图：把截图钉在屏幕上，可拖动、缩放，右键菜单（复制 / 另存为 / 关闭）。
- 确认截图 = 自动保存 PNG 到桌面 + 复制到剪贴板。
- 托盘常驻；托盘菜单：截图、设置、开机自启、退出；双击托盘 = 截图。
- 设置：热键、保存目录、自动保存开关、自动复制开关、开机自启。配置存 `%APPDATA%\WeSnap\settings.json`。

### 非目标（本期不做）

- OCR 取字、滚动自动截图（自动发滚轮）、录屏。
- 上传、分享、云同步、账号。
- 多语言、安装包、自动更新。
- 编辑已保存的历史图片。
- 全功能调色板（本期标注固定微信红，模型预留颜色/线宽字段）。

### 反面目标（做到了也算失败）

- 为了运行去关闭 Smart App Control 或要求管理员权限。
- 引入广告、联网上报、弹浏览器。
- 除「开机自启」外擅自写注册表；除自己的配置/日志外不写用户目录。

## 3. 约束与已探明环境

- Windows 11 Education 10.0.26300，单显示器，物理分辨率 2560×1600，缩放 175%（168 DPI）。
- **Smart App Control 处于启用状态，未签名 exe 一律被拦截**（临时目录与 `Z:\screenshot` 下均实测被拦）。
- 已安装 Python 3.14.7（`python.exe` / `pythonw.exe` 可用，Tk 9.0），pip 26.2.1；Pillow 13.0.0 可在本机安装（已在临时 target 验证），`ImageTk` 与 Tk 9.0 兼容。
- 无 .NET SDK（仅有运行时），无 winget / msbuild。系统自带 .NET Framework 4.8 的 `csc.exe` 可用，但产物 exe 同样会被 SAC 拦截。
- 交付目录 `Z:\screenshot`（非 git 仓库）。

由此推出的硬约束：**最终形态不能是自编译 exe**，必须以已签名的 `pythonw.exe` 宿主运行 Python 程序。用户侧通过 `.vbs` 启动器或快捷方式使用，不出现控制台窗口。

## 4. 方案

### 4.1 功能范围（对话中已定）

- A. 只有框选 + 保存（太素，放弃）。
- B. 微信核心复刻：框选 + 标注 + 贴图 + 保存（用户已选）。
- C. B + OCR + 自动滚动长截图 + 完整设置面板（工程量约 2–3 倍，放弃）。
- 最终：**B + 长截图（手动滚动拼接）**。

### 4.2 技术路线

| 方案 | 结论 |
|------|------|
| C# WinForms/.NET（8 或 4.8） | 体验最好、单文件小；但所有产物 exe 被 SAC 拦截，除非关闭 SAC（不可接受）。否决。 |
| Electron / Node | 托盘、截图、拼接都能做，但安装体积大、启动慢，打包产物同样是 exe。否决。 |
| **Python 3.14 + Tk 9.0 + Pillow + ctypes** | **选用**。`pythonw.exe` 有微软签名，SAC 放行；Tk 全屏无边框窗口 + Canvas 足以自绘微信式遮罩与工具栏；GDI 截图与剪贴板用 ctypes 直连；无 exe 产物。 |

依赖策略：仅 `Pillow`（图像裁剪、缩放、灰度匹配、PNG 编码）。若 pip 安装被安全策略拦截，退回纯 ctypes GDI/WIC 实现（工作量大，见风险）。

GUI 框架选 Tk 而非 PySide6：PySide6 下载约 200MB，且本工具界面几乎全是 Canvas 自绘，Tk 9 足够；依赖越少越稳。

## 5. 交互设计

### 5.1 截图主流程

```
按 Alt+A
  → 抓取全部屏幕 → 立即对每个显示器弹一个无边框置顶窗口（显示变暗截图）
  → 鼠标处十字光标，拖拽框选
  → 松开后显示选区边框 + 8 个手柄 + 下方工具栏 + 尺寸徽标
  → 标注（工具选中后可继续拖拽绘制；可撤销）
  → Enter / 双击 / 点「完成」：合成图片 → 存桌面 → 写剪贴板 → 关闭
  → Esc / 右键 / 点「取消」：关闭
```

工具栏（选区下方，靠屏幕底边时翻到上方；选区过小则浮在选区外侧）：

```
[▭] [◯] [↗] [✎] [A] [▦] [↶] | [长截图] [贴图] | [保存] [✓] [✕]
```

- `▭◯↗✎A▦` 标注工具、`↶` 撤销、`长截图`、`贴图`、`保存`（另存为对话框）、`✓ 完成`、`✕ 取消`。
- 图标全部用 Canvas 矢量绘制，不依赖图片资源。
- 颜色深色背景上工具栏描边 + 阴影，保证可见。

动作语义（实现者的决定，已写入本设计）：

- **完成（Enter / 双击 / ✓）**：按设置执行「自动保存 → 配置目录」「自动复制 → 剪贴板」，然后关闭编辑器；两个开关都关时退化为弹「另存为」对话框，避免丢图。
- **保存**：弹「另存为」对话框，写入合成图（标注已烘焙），保存成功后关闭编辑器；不写剪贴板。
- **贴图**：把合成图变成置顶浮窗并**关闭编辑器**，不保存、不复制（与微信一致）。
- **长截图**：进入滚动模式并隐藏编辑器。若当前已有标注对象，按钮置灰并提示「长截图不支持标注，请先撤销全部标注」；长截图完成后也不回到标注界面。
- 剪贴板/保存动作只发生在「完成」和「保存」上，别的操作不产生文件。

尺寸徽标：光标附近实时显示 `宽 × 高` 与选区左上角坐标。

键盘：`Esc` 取消，`Enter` 完成，`Ctrl+Z` 撤销，方向键移动选区 1px（Shift 10px）。热键再次按下 = 取消当前截图。

### 5.2 长截图流程

```
框选区域 → 点「长截图」
  → 遮罩窗口全部隐藏，只留：
      · 选区四周 2px 高亮边框（4 个置顶细窗，贴在选区外侧，不挡滚动、不进入抓取范围）
      · 控制面板（缩放后的已拼接结果 + 状态文字 + [完成] [取消]）
  → 用户把鼠标放在选区里，滚动滚轮，目标窗口自行滚动
  → 程序每 ~100ms 抓一次选区，检测变化→拼接→刷新预览
  → 点「完成」：保存到桌面 + 剪贴板，关闭
  → 点「取消」/Esc（控制面板有焦点时）：丢弃
```

**控制面板必须完全落在抓取矩形之外**，否则它自己的像素会每帧被拍进去、又被当成滚动内容参与拼接。放置顺序：选区右侧 → 选区左侧 → 选区下方 → 选区上方，选第一个放得下的位置。若选区几乎占满屏幕、四方都放不下，**禁用「长截图」按钮**并提示「选区太大，长截图需要选区外有放控制面板的空间」。

**不变量：任何 WeSnap 自己的窗口（控制面板、边框条、贴图、托盘气泡）都不得出现在最终长图里。** 长截图会话开始时隐藏所有贴图，结束后恢复；边框条位于选区外侧；控制面板位于抓取矩形之外。

控制面板文字示例：`已拼接 12 段 · 高 3840px`。

### 5.3 贴图

- 生成置顶无框窗口显示合成图，初始 100%。
- 左键拖动移动；四边四角拖拽缩放；`Ctrl+滚轮` 或滚轮缩放 25%–300%。
- 右键菜单：复制、另存为、关闭；`Esc` 关闭；双击关闭。
- 可同时贴多张。

### 5.4 托盘与设置

- 托盘图标（Canvas 画成小相机后转 ico）；提示文字「微截 · Alt+A」。
- 左键单击 / 双击：截图。右键菜单：截图、设置…、开机自启（勾选）、退出。
- 设置窗口（Tk Toplevel）：快捷键录制定框、保存目录选择、自动保存 ✓、自动复制 ✓、开机自启 ✓、保存/取消。热键注册失败时提示冲突并留在编辑状态。

### 6.1 文件结构

### 6.2 抓屏与 DPI

- 启动时 `SetProcessDpiAwarenessContext(PER_MONITOR_AWARE_V2)`，保证拿到物理像素。
- 抓屏：`GetDC(NULL)` → 兼容位图 → `BitBlt(SRCCOPY|CAPTUREBLT)` → `GetDIBits` → PIL `Image.frombuffer("RGB")`。多显示器按虚拟屏矩形一次抓全。
- Tk 坐标：Tk 9 可能仍按缩放换算逻辑坐标。实现第一步先探针验证（`winfo_screenwidth` 是否 2560）。若为逻辑坐标，统一在边界处按 `GetDpiForWindow/96` 做逻辑↔物理换算；所有裁剪、保存一律物理像素。
- 遮罩：每个显示器一个 `Toplevel`，`overrideredirect=True`、`-topmost`、`-alpha`，铺满该显示器。
- 字体在窗口内按当前 DPI 手动换算字号，保证工具栏不变形。

### 6.3 选区与渲染

- 选区状态：`Rect(x,y,w,h)`（物理像素）、8 手柄、拖拽模式（新建/移动/缩放/绘制）。
- 渲染分层（Canvas）：变暗全屏图（底）→ 选区原图（裁剪后贴回）→ 标注向量 → 边框/手柄/辅助线 → 工具栏。
- 性能：不整屏重绘。变暗图常驻；选区原图作为独立 image item 随选框更新（每次移动只做一次裁剪）。
- 标注坐标系相对选区左上角，统一裁剪到选区内，越界部分不绘制。

### 6.4 标注模型

- 类型：`Rect`、`Ellipse`、`Arrow`、`Pen`（点列）、`Text`、`Mosaic`（笔刷轨迹）。
- 公共字段：`color`（默认 `#E64340`）、`width`（默认 2）。本期界面不提供调色，字段预留。
- 文字：点按位置弹出 Entry 内嵌编辑，确认后成为 Text 对象；字体「微软雅黑」14pt，红色。
- 马赛克：8px 方块化，圆形笔刷（半径约 10px），点列记录，渲染时对裁剪区域做块采样。
- 撤销：对象列表末尾弹出（撤销只作用于最近一个对象，重做暂不做）。
- 合成：确认截图时按顺序把对象画到原图副本上（PIL ImageDraw + 方块采样），得到最终 PNG。

### 6.5 长截图

- 启动时抓第一帧为画布。轮询线程每 100ms 抓同一矩形。
- 帧间快速筛选：抽样 ~200 个像素点比较，几乎相同则跳过，不进入拼接。
- 拼接（`stitcher.py`，纯函数，便于测试）：

```
stitch(canvas, frame, params) -> (new_canvas, offset, confidence)

h = frame.height, w = frame.width
gray_canvas = 底部 max_overlap 行 -> 灰度、宽度缩到 ~320
gray_frame  = 顶部 max_overlap 行 -> 同上
对候选偏移 d ∈ [min_overlap, h - min_overlap]（粗扫步长 2，再邻域细化）：
    score(d) = mean(|canvas_gray_bottom(d) - frame_gray_top(d)|)
选 score 最小且 ≤ 阈值的 d：
    追加 frame[d:h]
否则：
    若 frame 已包含在画布中（向上滚动）：忽略该帧
    否则：整帧追加，标记低置信（可能重复内容）
```

- 参数初值：`min_overlap=16`、`max_overlap=min(h*0.9, h-16)`、阈值 12/255、匹配宽度 320。
- 上限：画布高 > 30000px 时停止追加并在控制面板提示。
- 轮询期间捕获失败（锁屏/RDP 断开）→ 跳过该帧，连续失败 5 次停止并提示。
- 控制面板与边框条一律位于抓取矩形之外，会话开始前隐藏全部贴图；抓取的每一帧都必须不包含任何 WeSnap 窗口。
- 已知限制：固定表头/侧栏的页面可能导致重复条带；用户向上回滚后再向下可能产生错位；选区外无空间放控制面板时不可进入长截图。文档与 README 中写明。

### 6.6 剪贴板

- 先写 `CF_DIB`（BGR 行序自底向上 + BITMAPINFOHEADER，24/32 位均可）。
- 同时注册 `CF_PNG`（PNG 字节流），兼顾现代应用。
- `OpenClipboard` 失败重试 3 次（每次 30ms）。

### 6.7 热键与托盘线程

- 热键：独立线程 `RegisterHotKey(None, id, mod, vk)` + `GetMessage` 循环；命中后投递到队列，Tk 主线程每 50ms 轮询队列执行（不跨线程操作 Tk）。
- 托盘：同一后台线程用 message-only 窗口 + `Shell_NotifyIcon`，菜单用 `CreatePopupMenu/TrackPopupMenu`；点击回调同样入队回主线程。
- 单实例：命名互斥量 `Local\WeSnap`，已存在则直接退出。

### 6.8 保存、设置、启动

- 文件名：`Screenshot_yyyyMMdd_HHmmss.png`，重名追加 `_2`；默认目录为桌面（`Environment.GetFolderPath` 等价物：`SHGetKnownFolderPath` 或注册表 `Desktop`），跟随系统桌面路径变化。
- 保存成功可在托盘气泡提示「已保存到桌面」。
- 设置 JSON 读写（原子写：临时文件 + 替换）；损坏时回落默认值并备份原文件。
- 开机自启：`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 写 `pythonw.exe "…\main.pyw"`；取消即删。
- 日志：`%APPDATA%\WeSnap\wesnap.log`，超过 1MB 滚动一份；异常兜底写日志 + 托盘提示，不静默死掉。

## 7. 边界与错误处理

| 场景 | 处理 |
|------|------|
| Alt+A 被占用 | 启动时 `RegisterHotKey` 失败→托盘警告气泡 + 自动打开设置窗口并聚焦快捷键录入；用户若未解决就关闭设置，程序留在托盘、托盘图标/提示持续标明「热键未生效」，点击托盘提示去设置。不允许无热键静默运行 |
| 多显示器不同缩放 | 每屏独立窗口，物理坐标换算；跨屏框选不支持（选区限定单屏），文档写明 |
| 截图时遮罩误入画面 | 先抓屏再弹窗；长截图开始前隐藏全部贴图，控制面板/边框条放在抓取矩形之外 |
| 抓屏失败 | 提示并退出本次截图 |
| 长截图无变化 / 停住 | 控制面板状态提示，可继续或完成；低置信拼接在面板上标黄提醒 |
| 剪贴板被占用 | 重试后失败→保存照常完成，气泡提示「已保存，但复制失败」 |
| 配置损坏 | 用默认值，原文件改名 `.bak` |
| 设置里目录不可写 | 保存时回落桌面并提示 |
| 显示器拔插 / 分辨率变化 | 每次截图重新枚举屏幕，不复用缓存 |
